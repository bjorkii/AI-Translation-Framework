# AI 감수 2차 — ch01 (용어집 준수 + 문체·톤 일관성)

- 대상: `chapters/ch01.md` (원문 대조는 1차에서 완료, 이 패스는 번역문만 봄)
- 수행: 기계 검사(`scripts/review_pass2.py`) + 독립 컨텍스트 문체·톤 감수(원문 미제공)
- 결과: **수정 후 통과** (중요 5건 · 경미 12건 → 16건 반영, 1건 판단 후 미반영)

## 1·2차 감수의 기준 차이

| | 1차 | 2차 |
|---|---|---|
| 기준 | 원문 | 번역 지침·용어집·한국어 |
| 보는 것 | 누락·오역·숫자/고유명사·덧붙임 | 문체 일관성·용어 표기 통일·번역투·가독성 |
| 감수자에게 주는 것 | 원문 + 번역문 + 지침 | **번역문 + 지침만** (원문 미제공) |
| 통과 기준 | 누락·오역 0건 | '중요' 0건 |

원문을 함께 주면 "원문에 충실한가"로 시선이 쏠려 한국어로서 어색한 문장을 놓친다. 반대로 2차만 하면 다듬다가 원문에서 멀어지는 것을 잡지 못한다. 그래서 2차 감수자에게는 원문을 주지 않는다.

## 2. 기계 검사

| 항목 | 결과 |
|---|---|
| 용어집 준수 | 통과 (적중 용어 모두 반영) |
| 표기 규칙(첫 등장 병기) | 통과 |
| 종결체 ~다 일관 | 통과 (존댓말 종결 0) |
| 제목 표기 방침 | 통과 (진행 중 발견한 영문 서명 겹낫표 1건 즉시 수정) |
| 천 단위 쉼표 | 통과 |

검사기를 두 번 고쳤다. 연도(1993 등)를 천 단위 쉼표 누락으로 잡던 문제, 그리고 낫표 사용을 무조건 혼용으로 보던 문제 — 표기 방침이 "영문은 이탤릭, 국문은 낫표"이므로 **낫표 안에 로마자 제목이 들어간 경우만** 위반으로 판정하도록 바꿨다.

## 3. 문체·톤 감수 (중요 5건)

| 유형 | 수정 전 → 수정 후 |
|---|---|
| 용어 일관성 | 국립영화보존재단 → 국립필름보존재단 |
| 용어 일관성 | 관람용 복사본 → 관람용 복제본 (용어집이 '복사'를 배제 대안으로 명시) |
| 번역투 | "영화가 … 볼 수 있고 … 지켜질 때" → "영화를 … 볼 수 있고 … 함께 남아 있을 때" (주술 호응) |
| 번역투 | "전문가 틀을 제공하며" → "전문가 조직을 마련해" (professional framework 직역) |
| 번역투 | "그림이 드러나면서 … 이해를 넓히고 있다" → "전모가 더 뚜렷해지면서 … 이해도 넓어지고 있다" |

경미 12건 중 11건 반영(문체 2, 용어 표기 2, 번역투 4, 가독성 2, 첫 등장 병기 1).

### 반영하지 않은 지적 1건

`잔존 소스 자료 → 남아 있는 원본 자료`는 반영하지 않았다. 원문이 `surviving original materials`와 `surviving source materials`를 서로 다른 말로 구분해 쓰므로 한국어에서도 구분을 유지하는 것이 맞다. **원문을 보지 않는 2차 감수 구조의 한계가 드러난 사례**로, 2차 지적을 반영할 때는 원문 확인이 필요한 항목인지 먼저 가려야 한다.
