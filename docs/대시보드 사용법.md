# 대시보드 여는 법

프로그램을 설치하거나 명령어를 입력할 필요는 없습니다. 폴더 안의 파일을 더블클릭하면 됩니다.

| 쓰는 컴퓨터 | 더블클릭할 파일 |
|---|---|
| 맥 (macOS) | **대시보드 실행.command** |
| 윈도우 | **대시보드 실행.bat** |

검은 창이 하나 뜨고, 잠시 뒤 브라우저가 자동으로 열립니다.

> **검은 창은 닫지 마세요.** 그 창이 대시보드를 돌리고 있습니다.
> 다 보고 나서 끝낼 때 창을 닫으면 됩니다.

브라우저가 저절로 열리지 않으면 주소창에 아래를 입력하세요.

```
http://127.0.0.1:8765/
```

## 처음 열 때 생길 수 있는 일

**맥에서 "확인되지 않은 개발자" 라며 열리지 않을 때**
파일을 마우스 오른쪽 버튼으로 누르고 **열기**를 고른 뒤, 다시 한 번 **열기**를 누르세요. 처음 한 번만 하면 됩니다.

**"Python 3가 필요합니다" 라고 나올 때**
- 맥: 안내에 따라 설치 창이 뜹니다. 설치가 끝나면 파일을 다시 더블클릭하세요.
- 윈도우: <https://www.python.org/downloads/> 에서 내려받아 설치합니다.
  설치 첫 화면의 **"Add python.exe to PATH"** 를 반드시 체크해 주세요. 이걸 빠뜨리면 다시 안내 문구가 나옵니다.

**이미 대시보드가 떠 있는데 실행 파일을 또 눌렀을 때**
떠 있던 것을 내리고 새 창에서 다시 띄웁니다. 창이 여러 개로 늘어나지 않습니다.
이전에 열려 있던 검은 창은 닫으셔도 됩니다.

**"쓸 수 있는 포트를 찾지 못했습니다" 라고 나올 때**
다른 프로그램이 자리를 차지하고 있습니다. 컴퓨터를 다시 켠 뒤 시도하면 대개 해결됩니다.

## 대시보드에서 할 수 있는 일

- **개요** — 전체 진행율, 경과 일수, 청크별 단계
- **청크** — 장별 목록. `보기` 칸에서 **원문 / 번역본 / 대조**를 새 탭으로 엽니다
- **용어집** — 확정된 용어 확인, 결정이 필요한 용어에 답하기, 용어 추가·수정·삭제
- **대조** — 원문부터 단계별 번역까지 나란히 보며 문단마다 **승인 / 반려 / 의견 메모**를 남기는 화면

청크 목록 오른쪽에는 `대기 0 › 정규화 20 › …` 처럼 단계별 개수가 있습니다. 숫자는 **지금 그 단계에 머물러 있는 청크 수**입니다. 눌러 보면 그 단계의 청크만 남고 나머지는 흐려집니다.

대조 화면에서 남긴 결정은 그대로 기록되어, 다음에 AI가 작업을 이어받을 때 반드시 확인하게 되어 있습니다. 담당자가 자리에 없어도 됩니다.

### 대조 화면 사용 요령

- **문장 짚어보기** — 문장 위에 마우스를 올리면 단계마다 같은 문장이 함께 표시됩니다. **클릭하면 그 문장에 고정**되어, 의견을 적는 동안 표시가 흐트러지지 않습니다. 같은 문장을 다시 클릭하면 풀립니다.
- **의견 메모** — 칸이 좁으면 오른쪽 아래 모서리를 끌어 넓히세요. 줄바꿈도 됩니다.
- **확정 버튼** — 승인이나 반려를 눌러도 아직 저장되지 않습니다. **확정**을 눌러야 기록됩니다. 잘못 눌렀으면 다시 눌러 선택을 취소하면 됩니다. 확정한 뒤에는 **철회**로 되돌릴 수 있습니다.
- **확인 유보** — 아무것도 하지 않은 문단은 '확인 유보'로 남습니다. 그대로 두어도 괜찮습니다. 의견이 있는 문단만 확정하고 넘어가셔도 됩니다.

### 용어보기

원문·번역본·대조 화면 오른쪽 위의 **용어보기**를 켜면 본문에서 용어집 용어를 짚어 줍니다.

- 아직 번역어를 정하지 않은 용어는 **배경색**으로, 이미 확정한 용어는 **점선 밑줄**로 표시됩니다.
- 마우스를 올리면 뜻과 표기 규칙이 보이고, **누르면 고정**되어 그 자리에서 번역어를 고칠 수 있습니다.
- 켠 상태는 기억되므로 다른 청크를 열어도 그대로입니다.

용어집 탭에서는 용어마다 **용례 N개 모두 보기**를 누르면 본문에 실제로 쓰인 문장을 넓은 칸에서 훑어볼 수 있고, 쪽번호를 누르면 그 원문으로 건너뜁니다.

### 확인이 필요하다는 표시가 보일 때

원문 화면에는 이런 표시가 나옵니다.

| 표시 | 뜻 | 눌러서 답할 수 있는 것 |
|---|---|---|
| 문단 경계 불확실 | 문장이 이어지는지 끊기는지 기계가 판단하지 못함 | `이어지는 문장` / `새 문단` |
| 읽기 순서 불확실 | 2단 조판 등에서 읽는 차례가 불확실함 | `순서 맞음` / `확인 필요` |
| 원본 대조 필요 | 표·도판을 기계가 되살렸으니 원본과 맞는지 확인 필요 | `원본과 맞음` / `틀림` |

**메모 칸**에 무엇을 보고 그렇게 판단했는지 적어 두시면, 다음에 AI가 그 자리를 볼 때 참고합니다. 메모만으로 확인이 끝나는 경우도 많습니다.

> 문단 경계·읽기 순서에 대한 판단은 **원문을 다시 만들어야** 화면에 반영됩니다. 기록은 바로 저장되니 그대로 두셔도 됩니다.

### 원문·번역문에 지시 남기기

본문에서 **글을 끌어 선택하면** '사용자 지시' 버튼이 뜹니다. 누르면 입력창이 열립니다.

- "이 표는 다시 만들어 주세요", "이 문단의 용어가 어색합니다" 처럼 **자유롭게** 적으시면 됩니다.
- 남긴 지시는 그 자리에 표시되어 계속 보이고, AI가 다음 작업을 시작할 때 반드시 확인합니다.
- 대조 화면의 승인·반려가 "이 번역이 맞나"를 묻는 것이라면, 이쪽은 **무엇이든 지시할 수 있는 통로**입니다.

### 서버 재실행

화면 오른쪽 위의 **서버 재실행**은 대시보드 프로그램 자체를 고쳤을 때 씁니다. 원문이나 번역문 내용은 새로고침만 하면 바로 반영되므로 평소에는 쓸 일이 없습니다.
